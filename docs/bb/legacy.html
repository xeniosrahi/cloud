📋 System Overview

System Type: Transport Commission Agent Management System built with PHP/MySQL. It manages freight deductions and payments to transporters (truck owners) on behalf of freight forwarders/factories.

🎯 Key Features

  • Voucher Management: Create, edit, and track freight vouchers
  • Settlement Processing: Generate payment invoices with complex deductions
  • Ledger System: Track advances, commissions, and adjustments
  • Payment Tracking: Cheque-based and cash payment modes
  • Reporting: Search, filter, and print payment advice
  • Session Management: Financial year-based data organization

⚠️ Critical Key Findings (Legacy Analysis)

Single-Tenant Architecture
The "Origin" (Consignor/Factory) is hardcoded. The system is deployed per client. New system MUST elevate "Origin" to a Master Entity.
Data Integrity Risk
Reliance on application-level calculations (JavaScript) rather than database procedures.
Security Risk
Plaintext passwords in `users` table, root database credentials in codebase, and lack of CSRF protection.
Settlement Logic
Balance calculation covers trip float, while "Net Payable" covers final settlement. These are distinct formulas.

⚠️ Critical Business Rules

Rule 1: Shortage can ONLY be added if voucher status is UNPAID
Rule 2: All transactions must fall within active Financial Session (Year)
Rule 3: LR (Lorry Receipt) numbers must be unique per session
Rule 4: Settlement locks vouchers from further edits (Read-Only mode)

⚠️ Architecture Issues

Critical Issues Identified:
  • Tight Coupling: Frontend and backend calculations are duplicated. Changes to formulas must be made in multiple places.
  • Session Management: Relies on $_SESSION without CSRF tokens. Vulnerable to CSRF attacks.
  • Single Tenant: "Origin" (Factory/Consignor) is hardcoded. Cannot support multiple factories without code changes.

Recommendation: Migrate to RESTful API + React/Vue SPA with centralized business logic.

1. calcTheForm() - Voucher Balance Calculation
File: index.php, details.php
Triggered: onKeyUp event on qty, freightPmt, advance, diesel, unloading fields

Purpose: Real-time calculation of trip balance as user types

function calcTheForm(theForm) {
    // Parse input values (default to 0 if invalid)
    var qty = parseFloat(theForm.qty.value);
    if (isNaN(qty)) qty = 0;

    var freightPmt = parseFloat(theForm.freightPmt.value);
    if (isNaN(freightPmt)) freightPmt = 0;

    var adv = parseFloat(theForm.adv.value);
    if (isNaN(adv)) adv = 0;

    var diesel = parseFloat(theForm.diesel.value);
    if (isNaN(diesel)) diesel = 0;

    var unld = parseFloat(theForm.unld.value);
    if (isNaN(unld)) unld = 0;

    var short = parseFloat(theForm.short.value);
    if (isNaN(short)) short = 0;

    // Step 1: Calculate Total Freight
    var result = qty * freightPmt;
    theForm.totfreight.value = result.toFixed(2);

    // Step 2: Calculate Balance
    // Formula: (TotalFreight + Unloading) - (Advance + Diesel + Shortage)
    theForm.balance.value = (result + unld - adv - diesel - short).toFixed(2);
}

Explanation:

  • Reads all input fields from the form
  • Handles NaN values by defaulting to 0
  • Calculates total freight (quantity × rate)
  • Calculates balance by adding unloading charges and subtracting expenses
  • Updates read-only fields in real-time
2. calculate() - Settlement Net Payable (Golden Formula)
File: addCheque.php
Triggered: Button click "Calculate" OR checkbox selection

Purpose: Calculate final net payable amount for selected vouchers

function calculate() {
    var sumF = 0;       // Sum of Freight
    var sumAdv = 0;     // Sum of Advances
    var sumDiesel = 0;  // Sum of Diesel
    var sumShort = 0;   // Sum of Shortages
    var sumTDS = 0;     // Sum of TDS
    var sumUnloading = 0; // Sum of Unloading charges
    var lrnosd = new Array();
    var salesd = new Array();

    // Loop through all checked CheckBoxes in GridView
    $('#Table1 input[type=checkbox]:checked').each(function() {
        var row = $(this).closest('tr')[0];
        lrnosd.push(parseInt(row.cells[3].innerHTML));  // LR No
        salesd.push(parseInt(row.cells[16].innerHTML)); // Sale ID
        sumF += parseFloat(row.cells[9].innerHTML);     // Freight
        sumTDS += parseFloat(row.cells[10].innerHTML);  // TDS
        sumAdv += parseFloat(row.cells[11].innerHTML);  // Advance
        sumDiesel += parseFloat(row.cells[12].innerHTML); // Diesel
        sumShort += parseFloat(row.cells[13].innerHTML);  // Shortage
        sumUnloading += parseFloat(row.cells[14].innerHTML); // Unloading
    });

    // Display aggregates
    document.getElementById('sumF').innerHTML = sumF;
    document.getElementById('netTDS').innerHTML = sumTDS;
    document.getElementById('sumAdv').innerHTML = sumAdv;
    document.getElementById('sumDiesel').innerHTML = sumDiesel;
    document.getElementById('sumShortage').innerHTML = sumShort;
    document.getElementById('sumUnloading').innerHTML = sumUnloading;

    // Calculate trip balance (before ledger deductions)
    let balance = sumF + sumUnloading - (sumTDS + sumAdv + sumDiesel + sumShort);
    balance = Math.round((balance + Number.EPSILON) * 1000) / 1000;
    document.getElementById('sumBalance').innerHTML = balance;

    // Get floating ledger amounts (from PHP-generated hidden elements)
    let netAdvance = parseFloat(document.getElementById('netAdvance').innerHTML);
    netAdvance = Math.abs(netAdvance);

    let netCommission = parseFloat(document.getElementById('netCommission').innerHTML);
    netCommission = Math.abs(netCommission);

    // Get extra charges (manual adjustments)
    let extra = parseFloat(document.getElementById('extraM').value);
    if (isNaN(extra)) {
        extra = 0;
        document.getElementById('extraM').value = 0;
    }

    // **GOLDEN FORMULA**
    // Net Payable = Balance - Floating Advances - Floating Commissions + Extra
    let sumPayable = Math.round((balance - netAdvance - netCommission + extra + Number.EPSILON) * 1000) / 1000;

    document.getElementById('sumPayable').innerHTML = sumPayable;
    document.getElementById('netPayable').value = sumPayable;

    // Hide/show payment button based on amount
    if (sumPayable <= 0) {
        $('#payFinal').hide();
    } else {
        $('#payFinal').show();
    }

    // Store selected IDs in hidden fields
    document.getElementById('lrnosd').value = lrnosd;
    document.getElementById('salesd').value = salesd;
    document.getElementById('payFinal').scrollIntoView();

    return false;
}

Explanation:

  • Iterates through all checked checkboxes in the voucher table
  • Sums up freight, advances, diesel, shortages, TDS, and unloading from selected rows
  • Fetches floating advances and commissions from ledger (calculated by PHP)
  • Applies the Golden Formula to calculate final net payable
  • Stores LR numbers and sale IDs for backend processing
  • Shows/hides payment button based on final amount

4. shortCal() - Shortage Calculation

function shortCal(theForm) {
    var qt = parseFloat(theForm.qt.value);
    if (isNaN(qt)) qt = 0;

    var rt = parseFloat(theForm.rt.value);
    if (isNaN(rt)) rt = 350; // Default rate

    var resulti = qt * rt;
    theForm.shrt.value = resulti.toFixed(2);
}

Explanation: Multiplies shortage quantity by rate (default ₹350/MT) to get penalty amount

2. Golden Formula - Net Payable Calculation (PHP)
File: addCheque.php (POST submit handler)
Triggered: When user submits invoice generation form

Purpose: Server-side calculation of final net payable (authoritative version)


if (isset($_POST['submit'])) {
    // Get selected sale IDs
    $sale = trim($_POST['salesd']);
    $sales = explode(',', $sale);

    // Load TDS percentage from config
    $json = file_get_contents('config.json');
    $config = json_decode($json, true);
    $tds = floatval($config['tds']); // e.g., 0.02 for 2%

    $transporterID = $_POST['transporterID'];

    // **STEP 1: Fetch Unsettled Advances**
    $queryAdvance = "SELECT SUM(AdvAmount) FROM advance 
                     WHERE transporterid LIKE '$transporterID' 
                     AND settleStatus LIKE 0";
    $dataAdv = mysqli_query($conn, $queryAdvance);
    $advance = 0;
    if (mysqli_num_rows($dataAdv) > 0) {
        while ($row = mysqli_fetch_assoc($dataAdv)) {
            $advance = $row['SUM(AdvAmount)'];
        }
    }

    // **STEP 2: Fetch Unsettled Commissions**
    $queryCommission = "SELECT SUM(CommAmount) FROM commission 
                        WHERE transporterid LIKE '$transporterID' 
                        AND settleStatus LIKE 0";
    $dataComm = mysqli_query($conn, $queryCommission);
    $netCommission = 0;
    if (mysqli_num_rows($dataComm) > 0) {
        while ($row = mysqli_fetch_assoc($dataComm)) {
            $netCommission = $row['SUM(CommAmount)'];
        }
    }

    // **STEP 3: Aggregate Selected Sales**
    $result = mysqli_query($conn, 
        "SELECT SUM(qty) as qty,
                SUM(freightPMT) as freightPMT, 
                SUM(advance) as advance,
                SUM(diesel) as diesel, 
                SUM(shortage) as shortage,
                SUM(unloading) as unloading 
         FROM sales 
         WHERE sno IN ($sale)");
    $resulto = mysqli_fetch_assoc($result);

    // Get extra charges
    $extraM = $_POST['extraM'];

    // **GOLDEN FORMULA**
    // Net Payable = (Σ Freight + Σ Unloading) 
    //               - (TDS + Σ Advance + Σ Diesel + Σ Shortage + Float Advances + Float Commissions)
    //               + Extra

    $grossPayable = ($resulto['qty'] * $resulto['freightPMT']) + $resulto['unloading'];
    $tdsAmount = ($resulto['qty'] * $resulto['freightPMT']) * $tds;
    $totalDeductions = $resulto['advance'] + $resulto['diesel'] + $resulto['shortage'] 
                       + $tdsAmount + $advance + $netCommission;

    $netPayable = $grossPayable - $totalDeductions + $extraM;

    // **STEP 4: Update Database**
    $chequeNo = strtoupper(mysqli_escape_string($conn, $_POST['chequeno']));
    $chqDate = date('Y-m-d', strtotime($_POST['chequeDate']));

    // Mark sales as PAID
    $query = "UPDATE sales 
              SET paidChequeDate = 'PAID ($chequeNo @ $chequeDate)' 
              WHERE sno IN ($sale)";
    mysqli_query($conn, $query);

    // Settle advances
    $advResolve = "UPDATE advance SET settleStatus = 1 
                   WHERE transporterid LIKE '$transporterID'";
    mysqli_query($conn, $advResolve);

    // Settle commissions
    $commResolve = "UPDATE commission SET settleStatus = 1 
                    WHERE transporterid LIKE '$transporterID'";
    mysqli_query($conn, $commResolve);

    // Insert invoice
    $queryBill = "INSERT INTO invoices 
                  (Transporter, lrnos, salenos, tds, advance, commission, netPayable, 
                   chequeNo, chequeDate, extraM, transporterid) 
                  VALUES ('$transporterName', '$lrn', '$sale', '$tdsAmount', '$advance', 
                          '$netCommission', '$netPayable', '$chequeNo', '$chqDate', 
                          '$extraM', '$transporterID')";
    mysqli_query($conn, $queryBill);

    // Get last inserted bill number
    $billNo = mysqli_query($conn, "SELECT LAST_INSERT_ID() LIMIT 1");
}

Explanation:

  1. Fetch floating advances: All unsettled advances for this transporter
  2. Fetch floating commissions: All unsettled commissions for this transporter
  3. Aggregate selected sales: Sum all quantities, freight, advances, etc.
  4. Calculate TDS: Multiply total freight by TDS percentage from config
  5. Apply Golden Formula: Calculate net payable using all components
  6. Update database: Mark sales as paid, settle ledgers, insert invoice

⚙️ Business Logic & Golden Formula

🏆 The Golden Formula - Net Payable

This is the most critical formula in the system.

Net Payable = Gross Payable - Total Deductions + Extra Charges

Where:

  • Gross Payable = Σ (Freight + Unloading)
  • Total Deductions = Σ (Advance + Diesel + Shortage) + TDS + Floating Advances + Floating Commissions
  • Extra Charges = Manual adjustments (can be positive or negative)

Formula Breakdown Table

Component Calculation Example (₹)
Total Freight (5 trips) Σ (Qty × Rate) 250,000
Total Unloading Σ Unloading 5,000
Gross Payable Freight + Unloading 255,000
Trip Advances Σ Advance 19,500
Trip Diesel Σ Diesel 9,500
Trip Shortages Σ Shortage 1,900
TDS (2%) Total Freight × 0.02 5,000
Floating Advances From advance table (unsettled) 8,000
Floating Commissions From commission table (unsettled) 2,000
Total Deductions Sum of above 45,900
Extra Charges Manual input 0
NET PAYABLE 255,000 - 45,900 + 0 ₹ 209,100/-
